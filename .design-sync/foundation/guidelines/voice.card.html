Projektseite, README, Release-Notizen, GitHub Englisch — immer, ohne Ausnahme. Eine deutsche Release-Notiz landet wörtlich auf der englischen Projektseite.
Die Anwendung selbst Die eingestellte Sprache — Deutsch oder Englisch, mehr gibt es nicht.
Fehlermeldungen vom Server Der Server benennt den Fehler, er übersetzt ihn nie. Die Oberfläche entscheidet, in welcher Sprache er erscheint.
Schlüssel von Diensten Gesehen auf plex   Gesehen auf Plex — plex, jellyfin sind interne Angelegenheiten und gehören nicht vor Augen.

Ton: sagen, was ist. „Bereits geladen" statt „Verfügbar ✓". Kein Ausrufezeichen, keine Begeisterung, keine Werbung — die Anwendung gehört Leuten, die ihre eigene Bibliothek verwalten.
Bei schlechten Nachrichten zuerst die Folge, dann der Grund. „Radarr ist nicht erreichbar — bitte Adresse und Schlüssel prüfen", nicht „Es ist ein Fehler aufgetreten (ECONNREFUSED)".
Nichts verschweigen, was jemand später merkt. Wenn zwei Server sich uneins sind, steht das im Hinweis — sonst nimmt jemand auf einem Server den Haken weg und versteht nicht, warum das Auge bleibt.
